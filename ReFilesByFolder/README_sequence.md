# 多层级文件自动重命名工具
规则：文件夹名称 + 智能序号（无原文件名）

=============================================
# 一、功能说明
1. 递归遍历所有子文件夹（无限层级）
2. 命名规则：
   - 文件夹内只有 1 个文件 → 直接使用【文件夹层级名称】
   - 文件夹内多个文件 → 【文件夹层级名称】+【序号】
3. 序号位数规则（自动）：
   位数 = 文件总数的字符长度 + 1
   示例：
   - 9个 → 1位+1=2位 → 01
   - 12个 →2位+1=3位 →001
   - 200个 →3位+1=4位 →0001
   - 1500个 →4位+1=5位 →00001
4. 支持自定义序号前缀（如 P → P001）
5. 支持强制固定序号位数
6. 保留文件后缀名
7. 安全不覆盖、不删除、不修改文件夹

=============================================
# 二、命名示例
```
原结构：
A
├── 文件.txt（1个）
└── B
    ├── 1.jpg（1个）
    └── C
        ├── a.png（12个）
        └── D
            └── test.pdf（200个）

重命名后：
A
├── A.txt
└── B
    ├── B.jpg
    └── C
        ├── B_C_001.png
        ├── B_C_002.png
        └── D
            ├── B_C_D_0001.pdf
            └── ...
            
```

=============================================
# 三、配置项说明
TARGET_FOLDER = 目标文件夹路径
CONNECTOR = 名称连接符（默认 _）
SEQ_PREFIX = 序号前缀（如 P → P001）
FORCE_DIGITS = 强制序号位数（0=自动）

=============================================
# 四、使用方法
1. 修改配置区的文件夹路径
2. 运行脚本
3. 查看控制台输出结果

=============================================
# 五、注意事项
1. 首次使用请先用测试文件夹验证
2. 脚本只会重命名文件，不影响文件夹
3. 自动跳过已存在文件，防止覆盖
4. 支持 Windows / Mac / Linux / 中文名称
