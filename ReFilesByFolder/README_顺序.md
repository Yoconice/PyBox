# 多层级文件自动重命名工具
规则：文件夹层级名称 + 智能序号（丢弃原文件名）

---

## 一、功能说明

1. **递归遍历**：无限层级扫描所有子文件夹
2. **命名规则**：
   - 文件夹内 **只有 1 个文件** → 直接使用【文件夹层级名称】（无序号）
   - 文件夹内 **多个文件** → 【文件夹层级名称】+【分隔符】+【序号】
3. **序号位数规则（自动）**：
   - 位数 = 文件总数的字符长度 + 1
   - 示例：
     - 9 个 → 1 位 + 1 = 2 位 → `01`
     - 12 个 → 2 位 + 1 = 3 位 → `001`
     - 200 个 → 3 位 + 1 = 4 位 → `0001`
     - 1500 个 → 4 位 + 1 = 5 位 → `00001`
4. **支持自定义序号前缀**（如 `P` → `P001`）
5. **支持强制固定序号位数**
6. **支持是否拼接根目录名称**（可开关）
7. **保留文件后缀名**
8. **安全机制**：不覆盖、不删除、不修改文件夹名称

---

## 二、命名示例

### 示例 1：开启根目录前缀（`use_root_prefix = True`）

```
原结构：
A
├── 文件.txt（1个）
└── B
    ├── 1.jpg（1个）
    └── C
        ├── a.png（12个）
        └── D
            └── test.pdf（200个）

重命名后：
A
├── A.txt
└── B
    ├── A｜B.jpg
    └── C
        ├── A｜B｜C｜001.png
        ├── A｜B｜C｜002.png
        └── D
            ├── A｜B｜C｜D｜0001.pdf
            └── ...
```

### 示例 2：关闭根目录前缀（`use_root_prefix = False`）

```
原结构：
A
├── 文件.txt（1个）
└── B
    ├── 1.jpg（1个）
    └── C
        ├── a.png（12个）
        └── D
            └── test.pdf（200个）

重命名后：
A
├── 文件.txt（根目录下文件无有效前缀，跳过）
└── B
    ├── B.jpg
    └── C
        ├── B｜C｜001.png
        ├── B｜C｜002.png
        └── D
            ├── B｜C｜D｜0001.pdf
            └── ...
```

> **注意**：关闭根目录前缀时，根目录下的文件因没有上层目录名称作为前缀，会被自动跳过。

## 三、配置项说明

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `TARGET_FOLDER` | 目标文件夹路径（必填） | — |
| `CONNECTOR` | 名称连接符 | `｜`（全角竖线） |
| `SEQ_PREFIX` | 序号前缀（如 `P` → `P001`） | 空（无前缀） |
| `FORCE_DIGITS` | 强制序号位数，`0` = 自动计算 | `0` |
| `USE_ROOT_PREFIX` | 是否拼接根目录名称 | `False` |

---

## 四、使用方法

1. 修改配置区的 `TARGET_FOLDER` 为目标文件夹路径
2. 根据需要调整其他配置项
3. 运行脚本
4. **查看预览**：控制台会输出所有文件的重命名方案预览
5. **确认执行**：输入 `y` 执行重命名，输入 `n` 取消

---

## 五、安全特性

1. **先预览后执行**：运行后先展示完整的重命名方案，确认无误后才执行
2. **自动跳过已存在文件**：目标文件名已存在时跳过，防止覆盖
3. **分隔符歧义预警**：原文件名中包含分隔符时会给出警告
4. **无需修改自动跳过**：新旧文件名一致的文件自动跳过
5. **仅重命名文件**：不修改文件夹名称、不删除任何内容
6. **支持中文名称**：完美兼容 Windows / Mac / Linux 及中文路径

---

## 六、注意事项

1. 首次使用请先用测试文件夹验证
2. 脚本只会重命名文件，不影响文件夹结构
3. 默认使用全角竖线 `｜` 作为分隔符，辨识度高且极少出现在原始文件名中
4. 如需使用其他分隔符（如下划线 `_`、短横线 `-` 等），修改 `CONNECTOR` 即可
