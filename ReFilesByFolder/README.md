# 多层级文件批量重命名工具

递归遍历文件夹，按层级自动重命名所有文件，支持无限子文件夹深度，安全不覆盖。

---

## 功能介绍
1. 根目录文件 → 【根文件夹名称_原文件名】
2. 第一层子文件夹内文件 → 【子文件夹名_原文件名】
3. 第二层及更深文件夹内文件 → 【所有上级文件夹名_当前文件夹名_原文件名】
4. 支持自定义连接符（默认为下划线 _）
5. 自动跳过已存在文件，不覆盖、不删除、不移动
6. 支持 Windows / Mac / Linux
7. 支持中文文件名与文件夹名

---

## 命名规则示例
```
原文件夹结构：
A
├── 1.txt
└── B
    ├── 2.txt
    └── C
        └── 3.txt

重命名后：
A
├── A_1.txt
└── B
    ├── B_2.txt
    └── C
        └── B_C_3.txt
```
---

## 使用方法
1. 打开 batch_rename.py
2. 修改 TARGET_FOLDER 为你要处理的文件夹路径
3. 可选修改 CONNECTOR 连接符（默认 _）
4. 运行脚本
5. 查看控制台日志

---

## 配置说明
TARGET_FOLDER = 你的文件夹路径
CONNECTOR = 连接符号，如 _ - @ # 等

---

## 注意事项
1. 第一次使用建议用测试文件夹测试
2. 脚本只会重命名文件，不会修改文件夹
3. 遇到同名文件会自动跳过，保证安全
4. 运行时不要打开被重命名的文件
